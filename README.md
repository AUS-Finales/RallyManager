# RallyManager

Sistema de gestión integral de campeonatos de rally.

## Descripción

RallyManager busca centralizar la administración de campeonatos,
carreras, etapas, tramos, inscripciones, tripulaciones, tiempos,
incidencias, penalizaciones y resultados.

## Arquitectura

- RallyManager.Domain: entidades y reglas de dominio.
- RallyManager.Application: casos de uso y servicios.
- RallyManager.Infrastructure: persistencia e integraciones.
- RallyManager.Api: API REST.
- RallyManager.Web: portal web.
- RallyManager.Mobile: aplicación móvil.

## Tecnologías

- C#
- .NET 10
- ASP.NET Core Web API
- Blazor WebAssembly
- .NET MAUI
- SQL Server
- Entity Framework Core
